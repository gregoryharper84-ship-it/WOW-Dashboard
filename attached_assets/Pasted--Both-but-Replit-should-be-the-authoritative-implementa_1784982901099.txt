**Both—but Replit should be the authoritative implementation.** The Custom GPT should orchestrate the workflow and explain decisions; Replit should perform the calculations, enforce the hard gates, store results, and prevent unsafe legs from reaching a final card.

## Recommended split

| Improvement                     | Custom GPT                                                            | Replit                                                                                     |
| ------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| New live 1–3 inning skill       | Add activation, required inputs, labels, and fail-closed instructions | Build the actual live-state model and data pipeline                                        |
| Live game-state verification    | Require it before analysis                                            | Retrieve inning, outs, bases, lineup position, pitch count, batters faced, and timestamps  |
| Hitter fantasy-score event tree | Describe required outputs                                             | Calculate the discrete scoring distribution                                                |
| H+R+RBI bust-risk model         | Require joint modeling                                                | Simulate correlated hits, runs, and RBIs                                                   |
| Weakest-leg finalizer           | Require it in every card workflow                                     | Make it a binding code gate that removes or replaces the weakest leg                       |
| Same-event concentration        | State limits and explain rejections                                   | Hard-block more than two same-event legs and excessive live exposure                       |
| Directional concentration       | Require fragility review                                              | Calculate concentration and reject structurally fragile cards                              |

| Postmortem ledger               | Request and interpret results                                         | Store predicted probabilities, actual outcomes, failure categories, and calibration errors |
| Regression testing              | Define expected behavior                                              | Run automated tests and prevent deployment when tests fail                                 |

The existing optimizer already requires weakest-leg elimination, mandatory shrinking, and a fragility audit. Those rules should remain visible in the Custom GPT, but they need to be **enforced in Replit**, where they cannot be skipped during a long conversational run. 

The same applies to pitcher workload and failure-path modeling: the GPT should invoke the correct skill, while Replit should calculate the regime probabilities, unconditional probability, and failure-path score.

## Best implementation order

1. **Custom GPT:** create the new skill and orchestration patch so the expected behavior is formally defined.
2. **Replit:** implement the live-state endpoint, event-tree models, hard gates, and ledger.
3. **Integration:** make the Custom GPT call Replit and preserve the backend terminal label.
4. **Regression tests:** replay these four slips and verify:

   * the two winning pregame pitcher cards remain eligible;
   * the three-same-event live card is rejected;
   * unsupported hitter fantasy-score legs fail closed;
   * Melton LESS 88.5 receives a cushion-risk downgrade;
   * no filler leg is retained to preserve card size.

## Final recommendation

Use this ownership rule:

```text
CUSTOM GPT = policy, orchestration, skill selection, explanation
REPLIT = data acquisition, simulation, calculations, hard enforcement, ledger
```

Were only one location available, choose **Replit**. A prompt-only patch may improve reasoning, but it cannot reliably guarantee fresh live-state data, binding weakest-leg removal, exact event simulations, or regression-tested enforcement.
