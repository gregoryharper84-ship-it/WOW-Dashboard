Replit task: implement WOW-PATCH-2026-07-02-IMPORTED-LEDGER-PROVENANCE-AND-STATUS-ESCALATION-GATE.

Goal: prevent pasted/imported/AI-generated/screenshot-derived prop ledgers from reaching MODEL_QUALIFIED_HOLD, MONEY_QUALIFIED, FINAL_APPROVED, or any playable-equivalent label unless the row has source-stamped, row-level verified data.

This is DRY RUN ONLY. No live betting, no orders, no execution.

Implementation target:
Add a pre-score provenance validator before any prop scoring, ranking, slip construction, or final-label assignment.

Required behavior:

1. Every externally supplied row starts as:
    IMPORTED_LEDGER_UNVERIFIED
2. If input_origin is not model_reconstructed, verified_api_reconstructed, or equivalent trusted internal reconstruction, require these fields before scoring:
    * player
    * team
    * opponent
    * game_date
    * market
    * line
    * side
    * source_url or source_path
    * source_timestamp
    * exact_query
    * l5_rows
    * l10_rows
    * l5_avg
    * l10_avg
    * l5_median
    * l10_median
    * l5_hit_count_at_line
    * l10_hit_count_at_line
    * player_status_timestamp
    * market_timestamp
    * final_lock_timestamp
3. If any required field is missing, force:
    final_label = WATCH or DATA_CONTRACT_FAIL
    can_execute = false
    terminal_failure_tag includes SOURCE_LEDGER_PROVENANCE_FAIL
    approval_blockers includes IMPORTED_LEDGER_UNVERIFIED
4. If a row only has summary averages and not game-by-game rows, force:
    terminal_failure_tag = SUMMARY_ONLY_NOT_MODEL_VERIFIED
    ceiling = WATCH
    can_execute = false
5. If pasted_claim_* fields exist, compare pasted values to reconstructed values.
    Trigger PASTED_LEDGER_CONTRADICTION if:
    * average differs by 10% or more
    * median differs by 0.5+ units
    * L5 or L10 exact-line hit count differs by 1+ game
    * side direction flips
    * injury/status context was omitted
    If contradiction changes the side:
    final_label = REJECT_DATA_QUALITY
    If side remains plausible but edge weakens:
    final_label = WATCH
6. Add MLB pitcher throwing-arm status escalation.
    If pitcher has recent:
    * Tommy John / UCL repair return
    * elbow comebacker
    * shoulder issue
    * forearm tightness
    * hand/wrist issue
    * velocity drop
    * early exit
    * skipped bullpen
    * pending bullpen
    * pitch-count restriction
    * next-start uncertainty
    Then require explicit named status output, not generic “starter recheck.”
    Example:
    STATUS_GATE_REQUIRED: repaired-elbow comebacker + next-start/workload uncertainty
    Until next-start status, bullpen clearance, pitch-count expectation, and role confirmation are verified:
    ceiling = WATCH
    can_execute = false
7. Add REASONED_NOT_MODELED kill.
    If the system attempts to upgrade a prop using language/fields like:
    * directionally consistent
    * plausible
    * starter recheck
    * role should be stable
    * average is close
    * seems supported
        but required data-contract fields are missing, force:
    terminal_failure_tag = REASONED_NOT_MODELED
    ceiling = WATCH
    can_execute = false
