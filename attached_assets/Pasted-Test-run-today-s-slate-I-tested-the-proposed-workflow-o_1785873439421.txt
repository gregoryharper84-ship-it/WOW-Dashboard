Ledger calculation

Once the CSV rows are returned, the ledger is deterministic:

first_inning_pitches =
count(rows grouped by game_pk where inning = 1)
first_inning_batters_faced =
count(distinct at_bat_number where inning = 1)
hits =
count(PA-ending events in single/double/triple/home_run)
walks =
count(events = walk or intentional_walk)
HBP =
count(events = hit_by_pitch)

LESS hit rate

P(BF>=5)

Test outcome

The source architecture is valid, but this chat’s web fetcher would not open the newly constructed Savant CSV URL because it only permits URLs already returned as exact search results. That is a tooling restriction—not a Baseball Savant data limitation.

The most practical production implementation is to add the Savant CSV request to the Replit backend. Replit can then fetch the pitch rows, aggregate inning one by game_pk, and submit the completed ledger directly to WOW. The 1IP lane remains TEST_ONLY and can_execute=false.
