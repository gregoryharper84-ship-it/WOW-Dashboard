Implement a targeted odds-ingestion fallback patch. Do not change LLP governance thresholds, taxonomy, approval gates, probability caps, or exposure rules.

PATCH NAME
LLP Odds Fallback Patch v16.1B

GOAL
Prevent a single odds-provider failure from causing a global board shutdown when enough board data exists to continue at a capped label.

CURRENT STATE
- ODDS_API_KEY is wired.
- _llp_no_vig_two_way() exists.
- no_vig_implied_probability already flows through scoring.
- LLP_SCOUT already exists as the ceiling when full validation is incomplete.
- LLP_APPROVED already requires complete validation and must remain unchanged.
- ESPN fallback patterns already exist elsewhere in the codebase.

REQUIRED SOURCE PRIORITY
For each game/market, attempt sources in this order:

1. The Odds API live h2h market
2. Secondary sportsbook/market source already available in the repo, if any
3. ESPN event/schedule data for event identity, start time, teams, and slate validation
4. PrizePicks Teams board reconstruction from submitted two-way decimal payouts
5. Manual/proxy reconstruction only when explicitly tagged and reproducible

IMPORTANT
ESPN is not a sportsbook price source. Use it only to validate:
- event exists
- event date/time
- teams
- status
- event not started/settled

Do not fabricate consensus odds from ESPN.

PRIZEPICKS RECONSTRUCTION
When a two-way PrizePicks Teams board provides decimal payouts for both sides:

raw_prob_a = 1 / decimal_a
raw_prob_b = 1 / decimal_b
overround = raw_prob_a + raw_prob_b
reconstructed_no_vig_a = raw_prob_a / overround
reconstructed_no_vig_b = raw_prob_b / overround

Store:
- source_type: prizepicks_reconstructed
- source_quality: proxy
- raw_implied_probability
- reconstructed_no_vig_probability
- reconstruction_timestamp
- board_price_timestamp
- reconstruction_method: two_way_decimal_normalization

This reconstruction is not sportsbook consensus.

LABEL RULES
A. Full sportsbook no-vig available and all other gates pass:
- normal full scoring path
- LLP_APPROVED remains eligible

B. No sportsbook no-vig, but valid PrizePicks two-way reconstruction exists:
- continue scoring
- final_label ceiling = LLP_SCOUT
- confidence_tier ceiling = LOW
- stake_tier = PASS
- big_stake_status = BLOCKED
- diagnostic_tags must include:
  - NO_SPORTSBOOK_COMP
  - PROXY_NO_VIG
  - PRIZEPICKS_RECONSTRUCTION

C. Event validation exists, but no usable two-way prices:
- final_label = LLP_REJECT or LLP_SCOUT according to current data-contract logic
- never global-board shutdown unless every candidate is unusable
- evaluate candidates independently

D. Event started, settled, missing from slate, or board unavailable:
- preserve current hard-kill behavior

BOARD-LEVEL BEHAVIOR
Remove the current behavior where one failed odds fetch causes a global NO PLAY for the entire board.

Replace it with per-candidate source resolution:
- each candidate attempts the fallback ladder independently
- one failed candidate must not invalidate other candidates
- global failure only when all candidates fail the data contract

NEW REQUIRED OUTPUT FIELDS
Per candidate:
- odds_source_primary
- odds_source_fallback_used: true | false
- odds_source_quality: live | official | reconstructed | proxy | unavailable
- sportsbook_no_vig_available: true | false
- reconstructed_no_vig_available: true | false
- reconstructed_no_vig_probability
- source_resolution_path: string[]
- source_failure_reasons: string[]
- label_ceiling_reason
- data_contract_status

DIAGNOSTIC TAGS
