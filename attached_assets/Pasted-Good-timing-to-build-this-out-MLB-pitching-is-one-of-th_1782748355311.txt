### CLAUDE — Gate Enforcement and Audit Layer

Claude's role stays analytical QA, but with sharper pitching data coming in, Claude can do more:

**1. Efficiency gap auto-flag**

When legacy platform returns pitcher data, Claude enforces:
```
If efficiency_gap > 0.15:
  → FLAG: LINE_ABOVE_RECENT_EFFICIENCY
  → Downgrade one tier, block Tier 1

If L5 K avg < (line × 0.85):
  → FLAG: L5_TREND_AGAINST_LINE
  → Cap at Watch unless leash + market agree

If leash_score > 7 AND line ≥ 17.5 outs:
  → REJECT_LEASH_KILL
```

**2. TTTO risk scoring**

Claude calculates third-time-through-order risk from BBRef log:
```
If pitcher's L5 avg IP < 5.0:
  → TTTO risk HIGH — opponent will see lineup 3× only 
    in ~40% of starts
  → For K overs above 5.5, this is a structural cap

If pitcher's last 3 starts: IP = [4.1, 5.0, 4.2]:
  → Leash trending short — flag LEASH_COMPRESSION
```
