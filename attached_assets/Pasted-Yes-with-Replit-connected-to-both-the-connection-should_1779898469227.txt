# How the connection works

## Step 1: ChatGPT sends board to Replit

When you upload PrizePicks screenshots or props here, ChatGPT/WOW should call your Replit endpoint:

```http
POST /input-board
```

Payload:

```json
{
  "source": "chatgpt",
  "board_type": "prizepicks",
  "date": "2026-05-27",
  "props": [
    {
      "player": "Player Name",
      "team": "TEAM",
      "opponent": "OPP",
      "sport": "MLB",
      "prop": "Strikeouts",
      "line": 4.5,
      "side": "MORE",
      "source": "PrizePicks"
    }
  ]
}
```

Replit saves the board and returns:

```json
{
  "board_id": "board_20260527_001",
  "status": "received"
}
```

---

## Step 2: Replit runs WOW scoring

Replit then calls your WOW scoring logic:

```http
POST /wow-score
```

WOW should return:

```json
{
  "board_id": "board_20260527_001",
  "model": "WOW",
  "approved_pool": [],
  "conditional_pool": [],
  "watch_pool": [],
  "reject_pool": [],
  "source_access_status": {
    "player_logs": "available",
    "official_status": "partial",
    "market_odds": "available",
    "projections": "available"
  }
}
```

This is the **primary model decision**.

---

## Step 3: Replit sends WOW output to Claude

Then Replit calls Claude:

```http
POST /claude-audit
```

Claude receives the WOW output and audits it.

Claude should return:

```json
{
  "board_id": "board_20260527_001",
  "props_to_keep": [],
  "props_to_downgrade": [],
  "props_to_reject": [],
  "missing_data_flags": [],
  "correlation_flags": [],
  "patch_recommendations": []
}
```

Claude’s role is not to make new picks.

Claude’s role is:

```text
Find bad assumptions.
Find missing data.
Find overpromoted legs.
Find correlation problems.
Find label mistakes.
```

---

## Step 4: Replit runs final arbiter

Then Replit should call:

```http
POST /final-arbiter
```

The arbiter compares:

```text
WOW original decision
Claude audit
Active model rules
```

Then decides:

```json
{
  "final_approved_pool": [],
  "final_conditional_pool": [],
  "final_watch_pool": [],
  "final_reject_pool": [],
  "accepted_claude_flags": [],
  "rejected_claude_flags": []
}
```

Important rule:

```text
Claude can challenge approval.
Claude cannot create approval.
WOW cannot ignore Claude silently.
```

Every Claude flag must be:

```text
Accepted
Rejected
Partially accepted
```

with a reason.

---

## Step 5: Replit returns final result to ChatGPT

Finally, ChatGPT receives the final Replit result and presents it cleanly to you.

```text
Final Approved Pool
Conditional Pool
Watchlist
Rejects
Claude Audit Notes
Slip Options if requested
```

# Best system design

## Replit should control the sequence

Inside Replit, the code flow should be:

```python
def run_connected_model(board):
    board_id = save_board(board)

    wow_output = run_wow_primary_analysis(board)

    claude_audit = run_claude_red_team_audit(
        wow_output=wow_output,
        active_rules=get_active_model_rules()
    )

    final_output = run_final_arbiter(
        wow_output=wow_output,
        claude_audit=claude_audit,
        active_rules=get_active_model_rules()
    )

    save_full_run(board_id, wow_output, claude_audit, final_output)

    return final_output
```
