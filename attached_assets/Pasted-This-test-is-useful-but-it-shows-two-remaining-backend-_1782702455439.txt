## Problem 1 — Gate order still needs fixing

Correct gate order should be:

```text
1. Missing price/orderbook → KALSHI_DATA_UNOBTAINABLE
2. Settlement grade F → KALSHI_REJECT_BAD_RULES
3. Liquidity grade F → KALSHI_REJECT_THIN_BOOK
4. No model probability → KALSHI_REJECT_UNCALIBRATED
5. Else run edge engine
```

Current behavior is skipping straight to:

```text
No model probability → KALSHI_REJECT_UNCALIBRATED
```

That is too late in the gate stack.
