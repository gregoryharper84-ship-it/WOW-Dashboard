## Recommended setup: keep both keys in Replit

Do **not** paste either key into:

* GPT Instructions
* Knowledge files
* The OpenAPI schema
* This chat
* Source code committed to Replit

GPT Actions securely support API-key authentication through Basic, Bearer, or a custom header. However, **The Odds API requires its key as an `apiKey` query parameter**, so the cleanest setup is to store both keys in Replit Secrets and let your Replit endpoint add the appropriate key before forwarding each request. ([OpenAI Help Center][1])

### 1. Add the keys to Replit Secrets

In your Replit project, open **Tools → Secrets** and add:

```text
ODDS_API_PAID_KEY=<your paid key>
ODDS_API_FREE_KEY=<your free key>
GPT_ACTION_SECRET=<create a separate long random password>
```

The third secret protects your Replit endpoint from unauthorized callers. The Odds API itself recommends storing keys in environment variables rather than exposing them in source code. ([The Odds API][2])

### 2. Route calls through your Replit backend

A FastAPI example:

```python
import os
from typing import Any

import httpx
from fastapi import FastAPI, Header, HTTPException, Query

app = FastAPI(title="WOW Odds Gateway")

PAID_KEY = os.environ["ODDS_API_PAID_KEY"]
FREE_KEY = os.environ["ODDS_API_FREE_KEY"]
ACTION_SECRET = os.environ["GPT_ACTION_SECRET"]

ODDS_API_BASE = "https://api.the-odds-api.com/v4"


def verify_action_secret(value: str | None) -> None:
    if not value or value != ACTION_SECRET:
        raise HTTPException(status_code=401, detail="Unauthorized")


async def request_odds_api(
    path: str,
    params: dict[str, Any],
    prefer_paid: bool = True,
) -> dict[str, Any]:
    keys = [PAID_KEY, FREE_KEY] if prefer_paid else [FREE_KEY, PAID_KEY]
    errors: list[dict[str, Any]] = []

    async with httpx.AsyncClient(timeout=30) as client:
        for key_type, key in zip(
            ["paid", "free"] if prefer_paid else ["free", "paid"],
            keys,
        ):
            request_params = {**params, "apiKey": key}
            response = await client.get(
                f"{ODDS_API_BASE}/{path.lstrip('/')}",
                params=request_params,
            )

            if response.status_code == 200:
                return {
                    "source_key_tier": key_type,
                    "requests_remaining": response.headers.get(
                        "x-requests-remaining"
                    ),
                    "requests_used": response.headers.get("x-requests-used"),
                    "request_cost": response.headers.get("x-requests-last"),
                    "data": response.json(),
                }

            errors.append(
                {
                    "key_tier": key_type,
                    "status_code": response.status_code,
                    "response": response.text[:500],
                }
            )

            # Only fall back for authentication, deactivation,
            # quota, or rate-limit failures.
            if response.status_code not in {401, 403, 429}:
                break

    raise HTTPException(
        status_code=502,
        detail={"message": "Both Odds API paths failed", "errors": errors},
    )


@app.get("/wow/odds/events")
async def get_events(
    sport: str,
    commence_time_from: str | None = None,
    commence_time_to: str | None = None,
    include_rotation_numbers: bool = False,
    x_wow_action_key: str | None = Header(default=None),
):
    verify_action_secret(x_wow_action_key)

    params: dict[str, Any] = {
        "includeRotationNumbers": str(include_rotation_numbers).lower(),
    }

    if commence_time_from:
        params["commenceTimeFrom"] = commence_time_from
    if commence_time_to:
        params["commenceTimeTo"] = commence_time_to

    return await request_odds_api(
        path=f"sports/{sport}/events",
        params=params,
        prefer_paid=False,  # inexpensive discovery call
    )


@app.get("/wow/odds/event-markets")
async def get_event_markets(
    sport: str,
    event_id: str,
    regions: str = Query(default="us"),
    bookmakers: str | None = None,
    x_wow_action_key: str | None = Header(default=None),
):
    verify_action_secret(x_wow_action_key)

    params: dict[str, Any] = {"regions": regions}
    if bookmakers:
        params["bookmakers"] = bookmakers

    return await request_odds_api(
        path=f"sports/{sport}/events/{event_id}/markets",
        params=params,
        prefer_paid=True,
    )


@app.get("/wow/odds/event-odds")
async def get_event_odds(
    sport: str,
    event_id: str,
    markets: str,
    regions: str = Query(default="us"),
    bookmakers: str | None = None,
    odds_format: str = Query(default="american"),
    x_wow_action_key: str | None = Header(default=None),
):
    verify_action_secret(x_wow_action_key)

    params: dict[str, Any] = {
        "regions": regions,
        "markets": markets,
        "oddsFormat": odds_format,
    }
    if bookmakers:
        params["bookmakers"] = bookmakers

    return await request_odds_api(
        path=f"sports/{sport}/events/{event_id}/odds",
        params=params,
        prefer_paid=True,
    )
```

A sensible routing policy is:

```text
Free key:
- Sports list
- Event discovery
- Basic low-cost calls

Paid key:
- Event markets
- Player props
- Multiple bookmakers
- Historical data
- Calls needed for exact two-way pricing

Fallback:
- Retry the other key only after authentication, deactivation,
  rate-limit, or quota failure
```

The Odds API returns quota information in the `x-requests-remaining`, `x-requests-used`, and `x-requests-last` response headers, so your gateway can track which key should be used. ([The Odds API][3])

### 3. Add the Replit gateway to your custom GPT

You must edit the GPT through the **ChatGPT web interface**; GPT building and editing are not available in the mobile apps. ([OpenAI Help Center][4])

1. Open **Explore GPTs**.
2. Select **My GPTs**.
3. Open **WOW Betting Engine**.
4. Select **Edit GPT**.
5. Scroll to **Actions**.
6. Select **Create new action**.
7. Under **Authentication**, choose:

   * **API key**
   * **Custom header**
   * Header name: `X-WOW-Action-Key`
   * Secret value: the same value stored as `GPT_ACTION_SECRET`
8. Paste an OpenAPI schema similar to this:

```yaml
openapi: 3.1.0
info:
  title: WOW Odds Gateway
  version: 1.0.0
  description: Secure odds and player-prop acquisition through the WOW backend.

servers:
  - url: https://YOUR-REPLIT-DOMAIN.replit.app

paths:
  /wow/odds/events:
    get:
      operationId: getOddsApiEvents
      summary: Get upcoming or live events for a sport
      parameters:
        - name: sport
          in: query
          required: true
          schema:
            type: string
        - name: commence_time_from
          in: query
          required: false
          schema:
            type: string
        - name: commence_time_to
          in: query
          required: false
          schema:
            type: string
        - name: include_rotation_numbers
          in: query
          required: false
          schema:
            type: boolean
            default: false
      responses:
        "200":
          description: Events and quota metadata
          content:
            application/json:
              schema:
                type: object
                additionalProperties: true

  /wow/odds/event-markets:
    get:
      operationId: getOddsApiEventMarkets
      summary: Get available sportsbook market keys for one event
      parameters:
        - name: sport
          in: query
          required: true
          schema:
            type: string
        - name: event_id
          in: query
          required: true
          schema:
            type: string
        - name: regions
          in: query
          required: false
          schema:
            type: string
            default: us
        - name: bookmakers
          in: query
          required: false
          schema:
            type: string
      responses:
        "200":
          description: Available event markets
          content:
            application/json:
              schema:
                type: object
                additionalProperties: true

  /wow/odds/event-odds:
    get:
      operationId: getOddsApiEventOdds
      summary: Get exact odds for selected markets on one event
      parameters:
        - name: sport
          in: query
          required: true
          schema:
            type: string
        - name: event_id
          in: query
          required: true
          schema:
            type: string
        - name: markets
          in: query
          required: true
          description: Comma-separated market keys
          schema:
            type: string
        - name: regions
          in: query
          required: false
          schema:
            type: string
            default: us
        - name: bookmakers
          in: query
          required: false
          schema:
            type: string
        - name: odds_format
          in: query
          required: false
          schema:
            type: string
            enum:
              - american
              - decimal
            default: american
      responses:
        "200":
          description: Exact event odds and quota metadata
          content:
            application/json:
              schema:
                type: object
                additionalProperties: true
```

Replace:

```text
https://YOUR-REPLIT-DOMAIN.replit.app
```

with your actual deployed Replit URL.

Then use the action’s **Test** button or GPT Preview to run:

```text
Call getOddsApiEvents for baseball_mlb.
```

OpenAI requires an OpenAPI JSON or YAML schema and recommends testing configured actions in Preview before updating the GPT. ([OpenAI Help Center][1])

## Important distinction

Adding the keys to your GPT will repair **Odds API acquisition**, but it will not repair the separate Replit governance failures from the last run. Your `/wow/engine/health`, warmup, governance-status, and scoring endpoints must also be reachable for a strict WOW full-model run. The two systems should remain separate:

```text
Odds API keys
→ Replit Secrets
→ WOW odds gateway

GPT Action secret
→ GPT Authentication field
→ Protects the Replit gateway

WOW governance service
→ Separate health, governance, and scoring endpoints
```
