Replit can build all 21 skills in the uploaded WOW v16 pack, plus the orchestration and audit infrastructure required to make them work as a real system rather than isolated prompt files. The registry identifies all 21 modules. skill-registry.json

1. Core research and modeling skills

These should be built first because nearly every sports analysis depends on them.

Skill	What Replit should build
Sports Research Analyst	Event identity, slate date, game status, injuries, starters, lineups, rotations, travel, credible-news verification
Historical Trend Researcher	Reproducible L5/L10/season datasets, role splits, home/road splits, outlier isolation, sample-quality checks
Player Prop Intelligence	Exact-line projections, median and average comparisons, role splits, usage, minutes, matchup, cushion tax, MORE/LESS bidirectional analysis
Game Script Simulator	Competitive, blowout, foul-trouble, pace-up, pace-down, starter-shortened and overtime scenarios with weighted survival rates
Market & Odds Intelligence	Sportsbook consensus, no-vig probability, line movement, source quality, market matching and edge calculation
Probability & EV Auditor	Model probability construction, probability caps, uncertainty, breakeven, payout friction and expected value
QA & Hallucination Auditor	Arithmetic recomputation, stale-source detection, schema validation, contradictions, unsupported claims and label validation

These seven form the minimum dependable research pipeline.

2. Sport-specific intelligence

These skills provide the specialist calculations rather than forcing one generic model to cover every market.

Skill	What it adds
WNBA Specialist	Rotation, role, pace, shot profile, matchup, travel, fatigue, teammate availability and blowout effects
MLB Pitching Expert	Strikeouts, pitching outs, earned runs, hits allowed, pitch count, leash, whiff rate, opponent K rate, catcher, umpire, park and weather
MLB Hitting Expert	Hits, total bases, fantasy score, home runs and plate appearances using contact quality, platoon, lineup position, starter, bullpen, park and weather
Weather Intelligence	Stadium weather, roof status, wind, temperature, air density, precipitation and Kalshi NHIGH forecast distributions
Referee & Umpire Tendency Analyst	Confirmed assignment analysis, strike-zone or foul tendencies, sample shrinkage and season/regime controls

The umpire/referee skill must return no adjustment when the assignment is unconfirmed, which is one of the acceptance tests. acceptance-tests.md

3. Slip, exposure and bankroll controls

These prevent individually reasonable picks from becoming a bad combined entry.

Skill	What it adds
Correlation & Slip Auditor	Same-game correlation, duplicate exposure, joint probability, combo breakeven, fragile structure and same-event multiplication checks
Bankroll & Risk Manager	Kelly sizing, unit recommendations, daily exposure, per-event exposure, drawdown control and Reliability Freeze limits
Sportsbook Promotion Optimizer	Promo EV after rollover, payout restrictions, boost caps, opportunity cost and hedge limitations

The bankroll skill should run only after eligibility is established. It must return no allocation when the capital lane is blocked. acceptance-tests.md

4. Kalshi intelligence

Kalshi Contract Intelligence

Replit can build this as a dedicated contract-audit layer covering:

* Contract and event identity
* Settlement-rule validation
* Market-open status
* Direct API orderbook provenance
* Price timestamp and 10-minute freshness gate
* Bid/ask spread and liquidity
* Fees
* Dry-run limit-fill feasibility
* Fill ledger tracking
* Canonical label normalization
* Weather bracket and sports contract support

Hard requirements remain:

* can_execute = false
* No live trading or market orders
* INVENTORY_EMPTY stops a sports scan
* Operator-supplied and screenshot prices cannot become direct/live prices
* Prices older than 10 minutes return DATA_UNOBTAINABLE
* Bare LLP_PLAYABLE_LIMIT_ONLY becomes LLP_PLAYABLE_LIMIT_ONLY_DRY_RUN

These requirements are established in the shared contract and Replit implementation instructions.  

5. Governance and system-maintenance skills

Skill	What it adds
Patch Governance & Architecture Manager	Patch registry, precedence, conflicts, duplicate rules, migrations, deprecation and required regression tests
QA & Hallucination Auditor	Final fail-closed check on every completed run
Sports Psychology Context Analyst	Verifiable situational context at a strictly limited weight; no unsupported claims about motivation or mental state

The psychology skill should never create a pick by itself or materially override statistical evidence. Its adjustment weight must remain capped. acceptance-tests.md

Every adapter should call the existing authoritative WOW engine where one already exists. It should not duplicate formulas in a second location. Every result should persist the run ID, skill version, sources, timestamps, calculations, blockers, label and downstream handoff. REPLIT_IMPLEMENTATION_PROMPT.md

One important implementation detail: Replit should not use the numerical priority in skill-registry.json as the actual runtime order. The canonical runtime order comes from ORCHESTRATOR.md, including specialist modeling before final market, EV, risk and QA review. ORCHESTRATOR.md
