## 1. Replit Provenance Label

**Endpoint affected:** `/wow/l10/v2`

Add a new response field:

```python
data_quality
```

Allowed values:

```txt
Verified
Manually Reconstructed
Proxy Only
Missing
```

Logic:

```python
TIER1_SOURCES = [
    "stats.nba.com", "statsapi.mlb.com", "site.api.espn.com"
]

MANUAL_RECONSTRUCT_SOURCES = [
    "baseball-reference.com", "bbref", "pd.read_html"
]

PROXY_SOURCES = [
    "espn narrative", "rotowire header", "fox sports header",
    "season average only"
]

if rows == 0 or not complete:
    data_quality = "Missing"
elif any(t in source.lower() for t in TIER1_SOURCES):
    data_quality = "Verified"
elif any(m in source.lower() for m in MANUAL_RECONSTRUCT_SOURCES):
    data_quality = "Manually Reconstructed"
elif any(p in source.lower() for p in PROXY_SOURCES):
    data_quality = "Proxy Only"
else:
    data_quality = "Manually Reconstructed"

response["data_quality"] = data_quality
```

Important: keep existing `confidence_tier`. This patch adds `data_quality`; it does not replace `confidence_tier`.

Add always-present field:

```python

```

Add on rejected responses:

```python
reject_reason
```

Allowed `reject_reason` values:

```txt
INPUT_FORMAT_ERROR
FETCH_FAILED
INSUFFICIENT_DATA
```

Rule:

```txt
INPUT_FORMAT_ERROR = validation failed before fetch
FETCH_FAILED = valid input, source errored/timed out
INSUFFICIENT_DATA = fetch succeeded but returned too few rows
```

This prevents bad input from looking like a real data gap.

## 3. Replit Health Endpoint

**New endpoint:** `/wow/health`

Purpose: return sport-specific Replit availability instead of only binary UP/DOWN.

Add:

```python
@app.route("/wow/health", methods=["GET"])
def wow_health():
    results = {}

    try:
        # minimal nba_api probe
        results["nba"] = "Available"
    except Exception as e:
        results["nba"] = f"Degraded — {str(e)[:60]}"

    try:
        r = _req.get("https://statsapi.mlb.com/api/v1/sports", timeout=5)
        results["mlb_pitcher"] = "Available" if r.ok else "Degraded"
    except Exception as e:
        results["mlb_pitcher"] = f"Degraded — {str(e)[:60]}"

    try:
        r = _req.get(
            "https://www.baseball-reference.com/robots.txt",
            timeout=5
        )
        results["mlb_batter"] = "Available" if r.ok else "Degraded"
    except Exception as e:
        results["mlb_batter"] = f"Degraded — {str(e)[:60]}"

    try:
        r = _req.get(
            "https://site.api.espn.com/apis/site/v2/sports/basketball/wnba/scoreboard",
            timeout=5
        )
        results["wnba"] = "Available" if r.ok else "Degraded"
    except Exception as e:
        results["wnba"] = f"Degraded — {str(e)[:60]}"

    results["cs2"] = "Manual Only — permanent"

    overall = "UP" if all(
        v == "Available" for k, v in results.items()
        if k != "cs2"
    ) else "PARTIAL"

    return jsonify({"status": overall, "sports": results})
```

This makes Replit report `PARTIAL` when NBA works but BBRef/WNBA/MLB batter paths are degraded.
