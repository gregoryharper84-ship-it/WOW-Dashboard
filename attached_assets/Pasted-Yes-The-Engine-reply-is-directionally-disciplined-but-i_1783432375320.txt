### 3. Push / whole-number line handling

This is a major one.

The engine needs to understand PrizePicks whole-number lines correctly.

Example:

**Courtney Williams MORE 5 Assists**

A sportsbook line at **4.5 assists** supporting the over does **not automatically validate** PrizePicks MORE 5. On PrizePicks, 5 is usually a push/reboot-style outcome, so the real cashing path is **6+ assists**.

Same issue for any whole-number line:

* **Ariel Atkins MORE 10 Points** needs 11+ to cash.
* **Courtney Williams MORE 5 Assists** needs 6+ to cash.
* **Cristopher Sánchez LESS 20 Outs** depends on whether 20 pushes or loses depending platform rules.

The Engine should convert every PP line into:

```text
cash threshold
push threshold
loss threshold
```

Then compare sportsbook/projection markets against the **cash threshold**, not just the displayed number.

### 4. Exact market comp versus adjacent-market comp

For each leg it should report:

```text
exact sportsbook market found: yes/no
adjacent market used: yes/no
market substitution allowed: yes/no
confidence cap if substituted
```

Example:

**Dearica Hamby MORE 18 Pts+Asts**

If no exact P+A book market exists, the Engine should still be able to use:

* player projection source

* PRA only as context, not validation

Then label:

```text
MODEL_QUALIFIED_HOLD
MARKET_UNVERIFIED_EXACT
```

Not just “no exact market found.”

```text
Sánchez group:
- Sánchez MORE 6.5 Ks
```

The Engine should choose the best edge inside each group instead of sending both forward.

### 7. Payout EV / slip structure

This is the biggest approval blocker. The engine should be able to calculate:

* slip type
* pick count
* payout multiplier
* break-even probability
* projected leg probabilities
* combined slip probability
* correlation penalty
* Goblin/Demon payout tax

If it cannot do that, it should say:

```text
SLIP_EV_NOT_CALCULATED
FINAL_APPROVAL_BLOCKED
```

That part should not be manual.

## Things the Engine may not be able to confirm on its own

These are acceptable holds:

* Final WNBA starting lineups if official lineups are not released yet.
* Exact sportsbook market if no book offers that exact stat type.
* PrizePicks line movement after the screenshot unless it has live PP access.
* Final player status if the official report still says questionable/GTD.
* True no-vig if only one book has a market.

Those can remain **HOLD**, but they should be explicitly labeled.
