## Express failsafe wrapper

Have Replit add this **before any catch-all frontend route**:

```js
app.get("/api/wow/kalshi/health", async (req, res) => {
  const base = {
    execution_rule: "DRY_RUN_ONLY_NO_LIVE_TRADING_NO_MARKET_ORDERS",
    can_execute: false
  };

  try {
    return res.status(200).json({
      ok: true,
      signal: "INVENTORY_EMPTY",
      source_status: "ROUTE_REACHABLE",
      message: "Kalshi health route is reachable. Inventory probe not yet confirmed.",
      ...base
    });
  } catch (err) {
    return res.status(200).json({
      ok: false,
      signal: "FAILED",
      source_status: "FAILED",
      message: String(err?.message || err),
      ...base
    });
  }
});
```

Once that route works, wire the real Kalshi/Flask probe behind it. The first goal is simply to make the Custom GPT action receive JSON.
