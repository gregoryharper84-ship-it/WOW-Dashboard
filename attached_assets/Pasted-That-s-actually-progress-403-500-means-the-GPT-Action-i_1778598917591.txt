## Immediate fix: make `/wow-daily-scan` always return JSON

Right now it is returning default HTML:

```html
Internal Server Error
```

GPT Actions do not handle that well. Add a JSON error wrapper.

If your app is Flask, add this to `main.py`:

```python
import os
import traceback
from flask import request, jsonify

@app.errorhandler(Exception)
def handle_unhandled_exception(e):
    app.logger.exception("Unhandled server error")
    return jsonify({
        "ok": False,
        "error": {
            "type": type(e).__name__,
            "message": str(e),
            "trace": traceback.format_exc()[-2000:]

            "market_odds": "Failed",
```

## Most likely causes of the 500

Check these in order:

| Possible cause                                             | Fix                                                             |
| ---------------------------------------------------------- | --------------------------------------------------------------- |
| Missing import                                             | Add import in `main.py`                                         |
| Wrong API key variable name                                | Replit has `ODDS_API_KEY`, `RUNDOWN_API_KEY`, `SCORING_API_KEY` |
| Code expects `WOW_API_KEY` but secret is `SCORING_API_KEY` | Change code or add `WOW_API_KEY` secret                         |
| Endpoint calls undefined function                          | Confirm function exists/imported                                |
| External API failed and exception was not caught           | Wrap each source call                                           |
| DB insert failed                                           | Return scan result before DB save, then debug DB                |
| Date `"today"` not handled                                 | Convert it to actual date server-side                           |
| Response schema mismatch                                   | Return the JSON shape from the Action schema                    |
