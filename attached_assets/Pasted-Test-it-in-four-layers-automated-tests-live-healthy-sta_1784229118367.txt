The most important pass/fail rule

The repair passes only if these two failures produce different results:

Worker unavailable
≠
Governance mismatch

Specifically:

* A worker outage should produce SCAN_WORKER_UNAVAILABLE or GOVERNANCE_UNAVAILABLE.
* A mismatch should only appear when the endpoint responded and the compared governance identities were actually different.

If another generic ClientResponseError appears without status, stage, and normalized error code, the repair is not complete.
