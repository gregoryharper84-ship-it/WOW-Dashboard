### What needs changing in legacy platform

The remaining fix is now fairly surgical:

1. **Complete the confidence model before market/EV/slip gates.** `market_no_vig` cannot be mandatory for confidence probability.
2. **Build `failure_path_matrix` during MLB pitcher auto-enrichment** instead of leaving the three required pathways uncomputed.
3. **Wire 1IP hydration into `simulate_1ip()` and the atomic probability ledger** so the acquired BF/PPA distributions generate `raw_probability`.
4. **Map acquired L10 data into `l10_distribution`** rather than claiming it is missing after retrieval.
5. **Do not let cross-slip exposure terminal-reject alternate board lines before confidence scoring.** Exposure belongs to the slip lane.
6. **Do not publish HIGH/MEDIUM/LOW confidence as a completed confidence result when calibrated probability is null.**
7. Fix the **1.6% ≥ 20% outlier comparison** and inspect the **current-opponent mapping**.

The next build should pass this hard assertion:

```text
rows_in = 61

for every model-eligible row:
    candidate_evaluation_completed = true
    raw_probability != null

and either:
    calibrated_probability + bounds exist
or:
    explicit calibration ceiling is preserved

missing market/no-vig:
    may block market/EV/slip
    must NOT erase confidence probability

unmodeled_model_eligible_rows = 0
```

So the verdict is: **the acquisition fixes are showing up, especially for 1IP, but the full-board confidence/optimizer fix is not complete yet. The break is now between hydration → specialist/failure-path model → probability ledger, not at board ingestion.**
