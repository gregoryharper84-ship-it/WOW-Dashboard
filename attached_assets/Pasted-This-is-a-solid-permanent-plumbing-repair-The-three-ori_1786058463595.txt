## Add response counters

The structured failure response should include enough counters to locate where execution stopped:

```json
{
  "props_received": 0,

  "rows_normalized": 0,
  "rows_rejected_schema": 0,
  "rows_entering_pipeline": 0,
  "rows_scored": 0,
  "rows_qualified": 0,
  "failed_stage": "request_normalization"
}
```

For a successful completed run:

```json
{
  "scoring_completed": true,
  "rows_received": 18,
  "rows_normalized": 18,
  "rows_scored": 18,
  "rows_qualified": 3,
  "rows_rejected": 15
}
```

Without these counters, future failures may still require digging through logs.

## Important hardening detail

This line is safe against crashes:

```python
enrichment if isinstance(enrichment, dict) else {}
```

But it could silently convert malformed upstream data into an empty object. Make sure it also emits a blocker:

```python
if not isinstance(enrichment, dict):
    return {
        "status": "REJECT_DATA_QUALITY",
        "primary_failure": "ENRICHMENT_SCHEMA_INVALID",
        "expected_type": "object",
        "actual_type": type(enrichment).__name__,
        "can_execute": False,
    }
```

Otherwise a contract defect could become an ordinary “missing evidence” result rather than being identified as malformed data.
