## What each connector should be used for

| Connector                               | Role in LLP                                                  | Status                                                  |
| --------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| `therundown.io`                         | Secondary odds / line feed                                   | Keep                                                    |
| `api.the-odds-api.com`                  | Primary sportsbook consensus / no-vig / market contradiction | Keep — this is one of the most important LLP connectors |
| `site.api.espn.com`                     | Schedule, scoreboard, team/player context, fallback status   | Keep, but do not treat as market consensus              |
| `api.balldontlie.io`                    | Backup stats feed                                            | Keep, but use as fallback/corroboration                 |
| `create-app-gregoryharper84.replit.app` | Your custom WOW/LLP backend                                  | Core connector                                          |

The Odds API free starter plan is useful because it provides 500 credits/month and covers sports/bookmakers/markets, making it the best immediate free connector for no-vig comparison and line-value checks. ([The Odds API][1])

Kalshi public market data should also be added because public market endpoints can be accessed without authentication at `https://external-api.kalshi.com/trade-api/v2`, and orderbooks expose YES/NO bids for binary markets. ([API Documentation][2])

## What you are missing

### 1. Kalshi public market-data connector

Add:

```text
external-api.kalshi.com
```

Purpose:

```text
market inventory
event metadata
market ticker
settlement rule
YES/NO orderbook
freshness check
```

Do **not** add authenticated trading or order endpoints. This should stay read-only.

### 2. MLB Stats API connector

Add:

```text
statsapi.mlb.com
```

Purpose:

```text
MLB schedule
game status
probable pitchers
box scores
player game logs
team stats
```

This is important because MLB sides/totals need starter confirmation, bullpen/game status, and game-log context. The public MLB Stats API ecosystem includes schedule/game/status style endpoints through the MLB StatsAPI wrapper docs. ([GitHub][3])

### 3. NWS weather connector

Add:

```text
api.weather.gov
```

Purpose:

```text
official weather
MLB park wind/rain/temperature
Kalshi weather lane backup
forecast timestamp
```

The National Weather Service API provides forecasts, alerts, observations, and other weather data. ([National Weather Service][4])

### 4. Open-Meteo connector

Add:

```text
api.open-meteo.com
```

Purpose:

```text
weather fallback
model comparison
non-NWS cross-check
```

Use NWS as primary for U.S. official weather and Open-Meteo as fallback/model comparison.

### 5. NBA/WNBA stats connector

Possible connector:

```text
stats.nba.com
```

or through your backend via `nba_api`.

Purpose:

```text
WNBA/NBA game logs
minutes
usage context
team pace
player recent splits
```

`api.balldontlie.io` is useful, but I would not rely on it alone for WNBA props or role-sensitive markets.
