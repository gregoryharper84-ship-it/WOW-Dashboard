# WOW Cross-Sport High Probability Selector

This package converts the logic behind a previously reviewed successful
four-leg card into a reusable daily skill.

It includes:

- cross-sport probability selection
- edge validation
- dependence control
- weakest-leg elimination
- immutable postmortem tracking
- permanent human confirmation

## Changes made during Claude's review (2026-08-05)

1. **Added YAML frontmatter to SKILL.md.** The original file had no
   `name`/`description` frontmatter block, which is the actual
   triggering mechanism the platform reads — as submitted, it would not
   have activated even if uploaded. Frontmatter now matches the format
   used by every other `wow-*` skill in the active stack.

2. **Moved governance.md into `governance/` and reformatted it as a
   proper `WOW-PATCH-TEMPLATE.md` submission.** The original file
   self-declared `Status: READY_FOR_SHADOW_MODE`. Per WOW governance,
   Claude does not self-approve patches and ChatGPT approval is required
   before any patch is treated as active — that status has been reset to
   `Proposed`. See `governance/WOW-PATCH-CROSS-SPORT-HIGH-PROBABILITY-SELECTOR.md`.

3. **Flagged an unresolved overlap with `wow-high-hit-engine`,** which
   already performs cross-platform probability-first ranking. This
   package adds weakest-leg elimination and an explicit cross-leg
   dependence audit that the existing skill doesn't have, but whether
   this skill runs *alongside* or *replaces* `wow-high-hit-engine` for
   the probability-ranking lane has not been decided. Documented in the
   patch's CONFLICTS/DEPENDENCIES section — do not deprecate
   `wow-high-hit-engine` on the basis of this package alone.

4. **Flagged unconfirmed legacy platform dependencies.** The governance file
   references an "immutable prediction ledger" and "cross-ticket
   exposure ledger" as health-check prerequisites for activation. These
   may not exist yet on the legacy platform backend. The patch calls for those
   specific checks to report `NOT_AVAILABLE` rather than silently
   passing if the ledgers aren't actually there.
