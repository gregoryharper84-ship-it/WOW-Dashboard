Use these exact instructions for Replit.

## Goal

Change `/wow-daily-scan` from:

```json
{"status":"started","message":"Scan running in background"}
```

to returning the completed scan results directly.

---

## 1. Open Replit

Open your project:

```text
create-app-gregoryharper84
```

Find the Flask backend file. It is usually one of:

```text
main.py
app.py
server.py
routes.py
```

---

## 2. Search for this route

Search in Replit for:

```python
@app.route("/wow-daily-scan"
```

or:

```python
wow-daily-scan
```

You should find something like:

```python
@app.route("/wow-daily-scan", methods=["POST"])
def wow_daily_scan():
    data = request.get_json()
    start_scan_background(data)
    return jsonify({
        "status": "started",
        "message": "Scan running in background. Check /scan-results for results."
    })
```

---

## 3. Replace the route with this

```python
@app.route("/wow-daily-scan", methods=["POST"])
def wow_daily_scan():
    try:
        data = request.get_json(silent=True) or {}

        result = run_daily_scan(
            date=data.get("date"),
            mode=data.get("mode", "DAILY_SPORTSBOOK_SCAN"),
            sports=data.get("sports", ["MLB", "NBA", "NHL"]),
            strict_board_lock=data.get("strict_board_lock", False),
            require_prizepicks_for_final=data.get("require_prizepicks_for_final", True),
            run_manual_l10_if_needed=data.get("run_manual_l10_if_needed", True),
            include_execution_report=data.get("include_execution_report", True),
        )

        if not isinstance(result, dict):
            result = {
                "ok": False,
                "status": "error",
                "message": "run_daily_scan did not return a dict",
                "raw_result": str(result)
            }

        result.setdefault("ok", True)
        result.setdefault("status", "completed")

        return jsonify(result), 200

    except Exception as e:
        return jsonify({
            "ok": False,
            "status": "error",
            "error": str(e)
        }), 500
```

## 4. If `run_daily_scan` does not exist

Search for the function that currently performs the scan. It may be named:

```python

```

Then replace this part:

```python
result = run_daily_scan(...)
```

with your real scan function name.

Example:

```python
result = run_wow_scan(data)
```

or:

```python

```
