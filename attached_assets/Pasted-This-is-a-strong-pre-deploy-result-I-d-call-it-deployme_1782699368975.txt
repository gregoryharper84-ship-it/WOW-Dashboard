## One thing I would double-check

This line worries me a little:

```text
No keys in bundle (all behind VITE_*) ✅ Clean
```

Be careful: **anything prefixed with `VITE_` is exposed to the browser bundle.**

So the rule should be:

```text
Safe in VITE_:
- public API base URL
- public feature flags
- frontend config

Never in VITE_:
- ANTHROPIC_API_KEY
- SCORING_API_KEY
- WOW_API_KEY
- Kalshi private keys
- any server secret
```

Correct setup should be:

```text
Frontend:
VITE_API_BASE_URL=https://create-app-gregoryharper84.legacy platform.app

Backend secrets only:
ANTHROPIC_API_KEY
SCORING_API_KEY / WOW_API_KEY
KALSHI_API_KEY_ID
KALSHI_PRIVATE_KEY
```

If that’s already true, you’re fine.
