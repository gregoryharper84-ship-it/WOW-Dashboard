Uploading the Markdown files to Replit is only the first step. **The engine will not automatically use them unless your runtime router explicitly loads, calls, and enforces them.**

The safest design is:

```text
ChatGPT request
→ Replit orchestration router
→ determine required skills
→ run every mandatory skill
→ apply lowest ceiling
→ cross-ticket governor
→ return invocation evidence
```

# 2. Make the router determine required skills

The GPT should not be trusted to remember every skill call. Replit should decide based on the normalized rows.

A simplified routing function:

```python
def determine_required_skills(request: dict) -> set[str]:
    required = {"wow.slip-probability-optimizer:v3"}

    rows = request.get("rows", [])
    cards = request.get("cards", [])

    for row in rows:
        sport = row.get("sport")
        stat = row.get("stat_family")
        participant_type = row.get("participant_type")
        direction = row.get("direction")

        if sport == "WNBA" and stat in {
            "POINTS",
            "REBOUNDS",
            "ASSISTS",
            "POINTS_REBOUNDS",
            "POINTS_ASSISTS",
            "REBOUNDS_ASSISTS",
            "PRA",
        }:
            required.add("wow.wnba-composite-prop-expert:v1")

        if sport == "MLB" and participant_type == "PITCHER":
            required.add("wow.mlb-pitcher-failure-path-expert:v2")

        if sport == "MLB" and stat == "STRIKEOUTS" and direction == "LESS":
            required.add("MLB_K_LESS_DIRECTIONAL_FIREWALL")

        if sport == "MLB" and stat == "PITCHING_OUTS" and direction == "MORE":
            required.add("MLB_OUTS_MORE_SURVIVAL_GATE")

    if len(cards) > 1 or detect_duplicate_theses(cards):
        required.add("wow.cross-ticket-exposure-governor:v1")

    return required
```

# 3. Fail closed when a required skill does not run

This is the most important enforcement.

After routing, Replit should verify that every required skill actually completed:

```python
required = determine_required_skills(request)
completed = set(result.skill_calls_completed)

missing = required - completed

if missing:
    return {
        "status": "REJECTED",
        "label": "REQUIRED_SKILL_NOT_EXECUTED",
        "missing_skills": sorted(missing),
        "lowest_ceiling": "NO_DATA_QUALITY",
        "can_execute": False,
    }, 422
```

The engine must never quietly continue using the old generic model because one specialist failed.

Use separate failure statuses:

```text
SKILL_NOT_LOADED
SKILL_CALL_FAILED
SKILL_OUTPUT_SCHEMA_INVALID
REQUIRED_FIELD_MISSING
PATCH_NOT_ACTIVE
GOVERNANCE_HASH_MISMATCH
```

# 6. Use a lowest-ceiling resolver

A downstream skill must never upgrade an earlier blocker.

```python
CEILING_RANK = {
    "REJECTED": 0,
    "SCOUT": 1,
    "WATCH": 2,
    "MODEL_QUALIFIED_HOLD": 3,
    "MARKET_VERIFIED_HOLD": 4,
}

def resolve_lowest_ceiling(skill_outputs: list[dict]) -> str:
    ceilings = [row["ceiling"] for row in skill_outputs]
    return min(ceilings, key=lambda x: CEILING_RANK[x])
```

Examples:

```text
WNBA Composite Expert = MODEL_QUALIFIED_HOLD
Generic optimizer = YES_MODEL_QUALIFIED
Final = MODEL_QUALIFIED_HOLD
```

```text
MLB Failure Path = WATCH
Slip optimizer = YES
Final = WATCH
```

```text
Cross-ticket governor = PORTFOLIO_REJECTED
All individual legs = YES
Final portfolio = PORTFOLIO_REJECTED
```
