## LLP v16 upgrade pack built

The pack extends the existing LLP Moneyline Probability Expert’s separate favorite/upset framework  and integrates exact market/no-vig controls consistent with the existing market auditor. 

### Complete installation bundle

[Download the LLP v16 Upgrade Pack](sandbox:/mnt/data/LLP_v16_Upgrade_2026-08-01.zip)

### Included deliverables

1. **Critical governing patch**

   * Slate integrity
   * Exact market normalization
   * Dynamic calibration
   * Quantified failure paths
   * Mandatory final refresh

2. **Updated LLP Moneyline Probability Expert**

   * Existing skill retained
   * New mandatory workflow appended
   * Separate probability and edge leaderboards
   * Official event IDs and normalized markets required

3. **Five new expert skills**

   * `wow.llp-slate-integrity-expert`
   * `wow.llp-market-normalization-expert`
   * `wow.llp-dynamic-calibration-expert`
   * `wow.llp-failure-path-expert`
   * `wow.llp-final-refresh-governor`

4. **Revised activation prompt**

5. **24 regression tests**

   * Wrong-day and wrong-year events
   * Started and completed games
   * Impossible duplicate-team scheduling
   * Missing soccer draw odds
   * Incorrect no-vig normalization
   * Favorite probability compared with underdog model
   * Point edge mislabeled as lower-bound edge
   * Universal 5% haircut
   * Starter and goalie changes
   * Moneyline/spread failure-path mismatch
   * Stale prices
   * Kalshi inventory and Recovery Mode controls
   * No forced output when nothing survives

6. **Manifest with recommended legacy platform pipeline hooks**
