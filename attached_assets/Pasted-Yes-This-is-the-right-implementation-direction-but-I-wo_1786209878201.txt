Your current WOWProbabilityOutputs structure is close, but I would make six changes.

Do not silently fall back from posterior quantiles to p_calibrated. If the model requires a posterior and none exists, that is an uncertainty-state issue, not a reason to pretend there is zero uncertainty.
Use a declared posterior central estimator. Median is reasonable, but p_true should not accidentally change meaning from model to model. Pick posterior_mean or posterior_median and version it.
Use proper quantile computation. samples[int(n * .10)] is crude and unstable for small samples.
Represent hard blocks separately from uncertainty. A HARD_BLOCK should prevent probability publication where required; it should never appear as merely one more risk factor.
Add dependence groups. ROLE, WORKLOAD, etc. are broad families; two risks inside one family can still represent the same latent uncertainty.
Track the source of each posterior draw. Otherwise you can produce a lower bound but cannot later explain why it widened.

from dataclasses import dataclass, field
from enum import Enum
from typing import List, Optional, Dict
import numpy as np


class EffectMode(Enum):
    MODEL_SHIFT = "MODEL_SHIFT"
    SCENARIO_MIXTURE = "SCENARIO_MIXTURE"
    VARIANCE_INFLATION = "VARIANCE_INFLATION"
    CALIBRATION_ADJUSTMENT = "CALIBRATION_ADJUSTMENT"
    FALLBACK_HAIRCUT = "FALLBACK_HAIRCUT"
    HARD_BLOCK = "HARD_BLOCK"


class RiskFamily(Enum):
    ROLE = "ROLE"
    WORKLOAD = "WORKLOAD"
    ENVIRONMENT = "ENVIRONMENT"
    MARKET = "MARKET"
    MODEL = "MODEL"
    DATA = "DATA"


class UncertaintyMode(Enum):
    POSTERIOR = "POSTERIOR"
    FALLBACK_HAIRCUT = "FALLBACK_HAIRCUT"
    BLOCKED = "BLOCKED"


@dataclass
class RiskFactor:
    risk_id: str
    risk_family: RiskFamily
    effect_mode: EffectMode

    state: str
    severity: str

    dependence_group: Optional[str] = None

    resolved: bool = False
    material: bool = True

    source: Optional[str] = None
    retrieved_at: Optional[str] = None
    source_confidence: Optional[float] = None

    # Only permitted in FALLBACK_HAIRCUT mode.
    estimated_effect_mean: Optional[float] = None
    estimated_effect_sd: Optional[float] = None


@dataclass
class PosteriorSample:
    hit_probability: float

    # Optional diagnostic decomposition.
    scenario_id: Optional[str] = None
    role_state: Optional[str] = None
    workload_state: Optional[str] = None
    environment_state: Optional[str] = None
    calibration_draw: Optional[float] = None


@dataclass
class WOWProbabilityOutputs:
    p_structural: float
    p_scenario: float
    p_calibrated: float

    posterior_samples: List[PosteriorSample] = field(default_factory=list)

    uncertainty_mode: UncertaintyMode = UncertaintyMode.POSTERIOR
    risks: List[RiskFactor] = field(default_factory=list)

    lower_quantile: float = 0.10
    upper_quantile: float = 0.90

    def _values(self) -> np.ndarray:
        return np.asarray(
            [x.hit_probability for x in self.posterior_samples],
            dtype=float
        )

    @property
    def blocking_risks(self) -> List[RiskFactor]:
        return [
            r for r in self.risks
            if r.material
            and not r.resolved
            and r.effect_mode == EffectMode.HARD_BLOCK
        ]

    @property
    def publishable(self) -> bool:
        if self.blocking_risks:
            return False

        if self.uncertainty_mode == UncertaintyMode.POSTERIOR:
            return len(self.posterior_samples) > 0

        if self.uncertainty_mode == UncertaintyMode.FALLBACK_HAIRCUT:
            return True

        return False

    @property
    def p_true(self) -> Optional[float]:
        if not self.publishable:
            return None

        values = self._values()

        if len(values):
            # Declare this convention globally.
            return float(np.median(values))

        # Fallback mode only.
        return float(self.p_calibrated)

    @property
    def p_lb(self) -> Optional[float]:
        if not self.publishable:
            return None

        values = self._values()

        if len(values):
            return float(
                np.quantile(
                    values,
                    self.lower_quantile,
                    method="linear"
                )
            )

        return self._fallback_lower_bound()

    @property
    def p_ub(self) -> Optional[float]:
        if not self.publishable:
            return None

        values = self._values()

        if len(values):
            return float(
                np.quantile(
                    values,
                    self.upper_quantile,
                    method="linear"
                )
            )

        return float(self.p_calibrated)

    def _fallback_lower_bound(self) -> float:
        """
        Fallback-only uncertainty treatment.

        Do NOT simply sum all penalties.
        Combine by dependence group upstream and pass only
        non-overlapping residual uncertainty here.
        """
        if self.uncertainty_mode != UncertaintyMode.FALLBACK_HAIRCUT:
            raise RuntimeError(
                "Posterior samples missing in authoritative posterior mode."
            )

        haircut = 0.0

        for risk in self.risks:
            if (
                risk.material
                and not risk.resolved
                and risk.effect_mode == EffectMode.FALLBACK_HAIRCUT
                and risk.estimated_effect_mean is not None
            ):
                haircut += max(0.0, risk.estimated_effect_mean)

        return max(0.0, self.p_calibrated - haircut)

One subtle distinction matters

A normal sports simulation already contains aleatoric variance.

For example, suppose a WNBA player is definitely playing 32 minutes. Even under that fixed state, she can score 12, 18, 24, or 31 points. That randomness belongs in:

P(points>17.5∣32 minutes).

You should not widen the epistemic posterior simply because individual games are volatile. That volatility is already inside the event distribution.

Epistemic uncertainty is instead:

Maybe she's really a 30–34 minute player rather than a fixed 32-minute player.

Maybe her estimated usage is 25–29%.

Maybe our calibration function for this cohort is slightly overconfident.

Maybe the workload-state probabilities are poorly estimated.

Those produce different plausible probability models, which is what the posterior should sample.

That gives you the clean identity:

Aleatoric uncertainty determines outcomes within a model
	​

Epistemic uncertainty determines uncertainty across models
	​

Market conflict should not normally become a posterior random variable

I'd preserve the rule we already established.

If market disagreement reveals new information, update the model.

If settlement/identity is mismatched, fix the comparison.

If it remains materially unexplained:

MARKET_CONFLICT_UNRESOLVED

can impose a ceiling or block money qualification.

But don't quietly represent:

market_conflict_sd = 0.025

and widen the posterior. That turns an unexplained contradiction into apparently quantified knowledge.

The revised four-pillar doctrine

I would canonize it exactly this way:

Probability tells us how likely we are to be right.
Uncertainty tells us how wrong that probability might be.
Payout tells us how right we need to be.
Structure tells us whether combining those legs creates a sound card.

And underneath it I would add a technical invariant:

Aleatoric risk belongs inside the event distribution. Epistemic risk belongs inside the distribution of plausible probabilities. Critical unknowns are blockers, not penalties.

That is the sentence that prevents future patches from quietly regressing WOW back into arbitrary haircut arithmetic.
