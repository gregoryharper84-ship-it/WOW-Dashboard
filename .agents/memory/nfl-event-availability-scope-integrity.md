# NFL event availability scope integrity

- **Date:** 2026-11-15
- **Typed reason:** `REPORT_SCOPE_MISMATCH` → `PLAYER_AVAILABILITY_UNVERIFIED`; no new canonical failure code was introduced.
- **Mechanism:** An official game-status report with a foreign event, sport, or team could still supply a listed designation before the availability gate rejected the scope. The same class existed in game-day inactives: plain-name or untagged entries could borrow team scope from a sibling mapping entry, and contradictory top-level `team`/`teams` values could be accepted because one matching field short-circuited validation. Separately, naive `datetime` objects were converted using the runner's local timezone, unlike naive ISO strings which are treated as UTC.
- **Detection point:** RED hosted regressions on PR #2669 reproduced three foreign-scope `OUT` failures plus one foreign-event conflicting-report failure; a second RED run reproduced three foreign-scope game-day inactive failures and one timezone-dependent timestamp failure; a third RED run reproduced six sibling-scope inheritance failures and one contradictory team/teams failure.
- **Fix:** Validate every supplied sport/event/team/teams field without short-circuiting. Validate official report scope before a designation can become authoritative. For game-day inactives, allow explicitly team-tagged mapping entries to establish only their own scope; string and untagged entries require a matching top-level `team` or singleton `teams` report scope and cannot inherit from sibling entries. Return non-decisive `REPORT_SCOPE_MISMATCH` evidence for invalid or contradictory scope. Normalize naive datetime objects as UTC.
- **Prevention artifact:** `artifacts/wow-engine/v17/test_nfl_event_availability_adapter.py` regressions `test_regression_out_of_scope_official_out_cannot_rule_player_out`, `test_regression_foreign_event_official_conflict_does_not_suppress_current_event_espn`, `test_regression_foreign_scope_gameday_inactives_cannot_preempt_current_event_clearance`, `test_regression_in_scope_gameday_inactives_string_inherits_report_team_scope`, and `test_regression_naive_datetime_is_normalized_as_utc`, `test_regression_untagged_inactive_entry_cannot_inherit_sibling_mapping_team`, and `test_regression_contradictory_report_team_and_teams_metadata_fails_closed`.
