## Goal and boundaries

Use the owner's existing Google AI Pro Antigravity entitlement to improve AMRT restoration, independent challenger analysis and Scout evidence collection without introducing a second engineering control plane or a fabricated fitted probability. This is a local-workstation agent integration: it is **not** an unattended Render or GitHub provider.

Antigravity officially discovers repository-root GEMINI.md and workspace agents at .agents/agents/<agent>/agent.md. These files are passive source configuration and require a user to open this repository in the supported Antigravity App, IDE or CLI and sign in to an eligible Google account. Google's account plan, quota and availability must be checked in-product; the repository does not perform authentication.

2. Confirm the root GEMINI.md loads as the workspace rule and choose the workspace agent 'wow-amrt-recovery' from the Agent Manager if supported by the chosen Antigravity surface.
3. Pilot against the **existing** GitHub AMRT incident #1841 only after verifying its current status, writer lease, responsible owner, and existing repair PR. Start read-only: request an exact-root-cause summary and a regression fixture plan.
4. If an authorized lease and assigned branch are independently confirmed, have Gemini prepare a small patch on that assigned branch for review. Otherwise publish a read-only patch proposal on the existing issue; **no competing PR is authorized; do not open one**.
5. Ask 'wow-model-challenger' to compare immutable pregame receipts against settled outcomes and propose a replay candidate (not a new numeric prediction). Optionally run 'wow-scout-evidence' to collect corroborated and contradictory sourced context.

7. Count success only when existing independent QA/Release and live Render/Action/Supabase evidence demonstrate the relevant repair. Record actual tokens/credits consumed, latency, accepted fixes, regression quality, and any repeats of the failure.
