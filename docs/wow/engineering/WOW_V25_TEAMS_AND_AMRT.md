## Operating loops

**Production loop:** Request → Discovery → Controlling specialist → V17 terminal reduction → Persistence → Product reconciliation → Independent golden-path acceptance.

**Continuous improvement loop:** Production outcomes and attributed failures → SIRT findings / postmortem → Betting Intelligence prioritization → Innovation benchmark or Model Excellence challenger → Class A/B/C Engineering and independent review → authorized deployment → measured post-release outcome → learning registry.

A failure is classified at the *first proven breaking boundary*: discovery, candidate handoff, identity, data quality, fitted artifact, scorer, routing, calibration, persistence, editor/MCP, source repository, CI/QA, protected merge, Render deployment, downstream decision or end-user acceptance. Preserve type-specific error codes. A correct fail-closed decision is **not** a model defect.

### AMRT recovery lifecycle

1. **Sentinel / Commander** deduplicates to an existing incident and assigns one fenced owner and severity.
2. **Dependency Investigator** reproduces precise event/sport/market and identifies first failing boundary; capture upstream receipts, model/artifact identity and expected versus actual behavior.
3. **Restoration Engineer** makes the smallest correct repair and adds focused, negative and adjacent regression evidence.
4. **Regression Specialist** independently challenges the reproduction, failure semantics, candidate conservation, and post-fix test evidence, without substituting for formal independent QA.
5. **Existing independent Review → QA → Release** authorizations check exact tested/reviewed SHA. Protected-contract and Class C changes go to the respective governed approval path.
6. **Authorized Production Engineering release** merges/deploys via the existing release controller, verifies deployed main SHA, safe original-scenario replay, persistence/reconciliation, Action/MCP and absence of new critical regressions.
7. **Independent Golden-Path Acceptance** issues a separate acceptance receipt; Reporter/Conductor reconciles final closure. Nonfinal cases retain AMRT ownership, blocker and re-entry.

If AMRT establishes that fitted model redesign, calibration or thresholds are required, **Model Excellence** owns a linked Class C *challenger* experiment; **AMRT keeps the production recovery incident** until its own resolution or typed justified disposition. No upgrade of an uncertified challenger during restoration.

### Deadlock/fallback policy

After repeated identical holds or stalled handoffs, the Deadlock Breaker distinguishes (a) pending CI/QA evidence, (b) reproducible code defect, (c) missing CODEOWNER/security/Release authorization, (d) writer lease and identity conflict, (e) provider outage, and (f) deployment drift. Reconcile exact outcome/PR/lease first. Route repairable causes to the existing authorized writer or a governed replacement **only once stale ownership is conclusively fenced**. Unavailable approval is not repaired by rerouting to a different self-approver. Expired lease alone grants no takeover. Never hide a failed action or spend retries until evidence becomes available.
