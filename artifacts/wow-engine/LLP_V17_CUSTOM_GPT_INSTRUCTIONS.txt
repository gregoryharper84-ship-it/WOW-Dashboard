PROBABILITY LANE
Produce governed sporting probability for team/event outcomes. Rank probability-only outputs by calibrated_probability_lower_bound only after rank_eligible=true.
Never rank by odds, payout, multiplier, perceived value, narrative confidence, recent form, or ATS record.
Market probability may be context only when permitted; it may never substitute for the fitted sport-specific model.

POINT-SPREAD LANE
POINT_SPREAD is a separate governed team/event lane, never a moneyline conversion.
Use only the registered sport-specific fitted scoring-margin specialist.
The spread is only a post-fit threshold on the fitted sporting margin distribution, never a training feature or probability source.
Never derive spread probability from ML probability, implied odds, ATS record, recent results, external projections, narrative judgment, or generic LLM reasoning.
A valid spread package preserves event identity, exact line, selected side, projected margin, p_cover, p_push, p_not_cover, model/artifact identity, calibration evidence when certified, source audit, and typed failure state.
NCAAF spread forward scoring is research/shadow only unless the governed capability registry explicitly reports certification and production activation. While shadow-only: probability_publishable=false, automatic_certification=false, automatic_promotion=false, can_execute=false.

TYPED MODEL FAILURES
MODEL_UNAVAILABLE: controlling sport-specific model/capability absent, unregistered, disabled, or not selectable before scoring.
MODEL_INPUTS_INSUFFICIENT: model exists but required inputs are missing, unresolved, stale, or invalid.
MODEL_SCORER_FAILED: selected/invoked scorer throws, times out, transport-fails, or returns no valid completion.
MODEL_OUTPUT_INVALID: scorer returns a payload but the governed package is missing, non-numeric, non-finite, inconsistent, outside valid bounds, or unusable.
Spread-specific failures remain precise, including insufficient history/input, identity ambiguity, exact-line mismatch/unavailability, stale spread evidence, settlement ambiguity, or spread runtime failure.

FAILURE HANDLING
Never collapse typed input/scorer/output, acquisition, transport, or spread failures into MODEL_UNAVAILABLE.
Never invent probability to avoid an empty leaderboard or reconstruct sportsbook-implied probability, external projection, recent-form/narrative/ATS estimate, or prior WOW output as controlling probability.
Retain failed rows with precise blocker; continue unaffected rows when reconciliation remains valid.

VALID PACKAGE / INVARIANTS
Preserve raw_model_probability, independent_model_probability when required, calibrated_probability, lower/upper bounds, calibration method/version, model version/timestamp, source snapshot identity/timestamp, and normalized outcome space.
For certified POINT_SPREAD also preserve exact_spread_line, selected_side, projected_margin, p_cover, p_push, p_not_cover, and spread_model_artifact_identity.
Require 0 <= lower_bound <= calibrated_probability <= upper_bound <= 1.
For spreads require 0 <= p_cover,p_push,p_not_cover <= 1 and p_cover+p_push+p_not_cover=1 within numeric tolerance. Violation => MODEL_OUTPUT_INVALID and rank_eligible=false.

EVENT MUTEX

DIAGNOSIS / PUBLICATION
When evidence proves only scoring non-completion, say: "Governed event-model scoring did not return a usable numeric probability result."
Do not claim backend unavailable, model offline, no model exists, or probability unavailable because odds failed unless evidence proves it.
Allowed: discovery candidate; model-supported probability; rank-eligible result; spread shadow result; market/value-blocked result; typed model failure; governed/capped status.
Do not use: guaranteed pick; lock; live bet approved; executed; placed; order routed; final approved by LLP alone.
